# AI 视频与漫剧成本测算器 ai-video-cost-calculator

## 1. 一句话

漫剧一条到底多少钱：输入剧本（时长、镜头数、风格、条数），各家模型、批量流水线、外包市场价、代码渲染的成本一次算清。

在线演示：待部署后填写（GitHub Pages）。

## 2. 它解决什么问题

AI 视频和漫剧的价格信息散、口径乱：模型按秒收费、外包按条报价、批量有起订门槛、代码渲染号称零成本但要花时间。想做 10 条漫剧，不知道该自己生成、外包，还是写代码渲染，拍脑袋定的结果常常是选了最贵的路。这个工具把四种路放在同一张表上比：同一份剧本，各家模型多少钱、批量流水线多少钱、外包多少钱、代码渲染多少钱，一眼看清差价在哪。

## 3. 输入来源与覆盖

- 剧本参数（用户输入）：视频条数、每条镜头数、每镜头秒数、风格、重生成率、汇率、质检分钟数、时薪、代码渲染耗时。
- 模型单价表（src/lib/pricing.ts）：24 行，2026-11-18 已按官方定价页核实。Sora 2 已下线（现行价已删除）；Veo 3 系列 6 行按 count 计费（官方未注明 1 count = 多少秒，不换算成本、不参与比较）；Kling 2.5 Turbo 4 行按 Units/秒计费（按 Standard Package 500 美元/3250 Units 换算成美元）；即梦 4 行按会员档位分行（人民币按秒）；海螺 02 列为历史模型（分档价写在备注里，无统一单价）；现行旗舰 MiniMax-H3 2K 0.80 元/秒；Runway Gen-4、Pika 2.5、Pika H3 Flex、Luma Ray 3.2 4 档按 credits/次计费（换算依据写在表里）。凡是经过换算的成本，结果里一律标为换算。
- 漫剧外包市场价（src/lib/pricing.ts）：单条 300-800 元、100 条起订 280 元/条，来源 2026-11-17 调研（小红书与行业文报价），状态为参考价，不是官方定价。
- 风格建议重生成率：写实 25%、动画 20%、漫剧 35%，是可改的假设默认值，不是实测数据。

## 4. 测算规则

### 4.1 总量

总镜头数 = 视频条数 × 每条镜头数；总秒数 = 总镜头数 × 每镜头秒数。

### 4.2 模型直接成本

按秒计费的模型：直接成本 = 总秒数 × 单价 × 汇率（美元价才乘汇率，人民币价不乘）。按条计费的模型：直接成本 = 总镜头数 × 单价（美元价乘汇率，人民币价不乘）。按 Units/秒计费的模型（Kling 2.5 Turbo）：先按套餐价把 Units 换算成美元/秒（1 Unit = 0.15386 美元），再按秒算，成本标为换算。按 credits/次计费的模型（Runway Gen-4、Pika、Luma）：生成次数 = 总镜头数 × ceil(每镜头秒数 ÷ 每次生成秒数)，不足一次按一次算（假设）；成本 = 生成次数 × 每次 credits 数 × 每 credit 美元价 × 汇率，标为换算。按 count 计费的模型（Veo 3 系列）不换算成本、不参与比较；已下线的模型不参与比较。金额保留两位小数。

### 4.3 含重生成成本

期望成本 = 直接成本 ×（1 + 重生成率）。重生成率默认按风格建议（漫剧 35%），可在页面上改，范围 0 到 5。

### 4.4 批量流水线成本

流水线成本 = 期望成本 + 视频条数 ×（质检分钟数 ÷ 60）× 时薪。质检与时薪为 0 时，流水线成本等于期望成本。

### 4.5 漫剧外包市场价

单条价：300-800 元/条 × 条数。批量价：100 条起订 280 元/条，条数未达 100 时不适用。节省额 = 外包价 - 最便宜模型的期望成本，低价与高价各算一笔。

### 4.6 代码渲染成本

直接成本恒为 0（本地 Chromium 无头渲染加 ffmpeg，无 API 调用）。本地渲染耗时 = 总秒数 × 每秒成片渲染耗时 ÷ 60（分钟），默认每秒成片需 6 秒计算（30fps 下每帧约 0.2 秒）。人工成本 = 渲染耗时（小时）× 时薪，时薪为 0 时不计。

### 4.7 示例数值（场景 A：10 条漫剧，每条 5 镜头，每镜头 5 秒，重生成率 35%，汇率 7.1）

总秒数 250 秒，总镜头 50 个。最便宜是 Luma Ray 3.2 360p，期望成本 28.76 元（直接 21.30 元，换算），注意这是最低分辨率档；即梦超级会员 Flash 70.88 元，Kling 2.5 Turbo 无音频 720p 110.61 元（换算），MiniMax-H3 2K 270.00 元；最便宜模型比外包单条低价省 2971.24 元、比高价省 7971.24 元；代码渲染直接成本 0 元、耗时 25 分钟。场景 B（100 条）最便宜仍是 Luma Ray 3.2 360p 287.55 元，批量外包价 28000 元，代码渲染 250 分钟。数值由测试断言锁定，见 src/lib/costcalc.test.ts。

## 5. 怎么用

打开页面，先点一个示例场景（10 条小批量、100 条批量、1 条单品测试），再改剧本参数：条数、镜头数、每镜头秒数、风格、重生成率、汇率、质检时间、时薪。模型单价直接在表里改，改完结果实时重算。看三张卡：总成片、最便宜的模型、代码渲染；再看模型成本表、外包对比、代码渲染对比三节。单价标着待核实的模型，用之前先打开官方定价页核对一遍再填；按 count 计费与已下线的模型不参与比较，单价栏不可改。

## 8. 确定性说明

100% 确定性，零大模型调用。代码算的：总秒数、总镜头数、四种成本、节省额、排序、代码渲染时间。查表的：模型单价、漫剧外包价、风格建议重生成率。用户输入的：剧本参数、汇率、质检时间、时薪、渲染耗时。同一输入同一输出，测试里有确定性断言。页面不上传任何数据，粘贴与输入只在浏览器本地算。

## 9. 合规边界

- 不涉及股票、加密和资金托管；不做采购、不下单、不代付。
- 价格只作决策参考：模型单价已按 2026-11-18 官方定价页核实，外包价是行业文引用价，汇率与重生成率是假设值。按次计费不足一次按一次算是假设，不是官方口径。
- 不编造数据：没有来源的价格不填数字，标待核实；没有实测依据的默认值写明是假设；官方未给的换算关系（如 1 count = 多少秒）不默认、不猜测。

## 10. 局限与下一步

- 计费单位不统一：Veo 3 按 count 计费，官方未说明 1 count = 多少秒，这 6 行不参与成本比较；Sora 2 已下线；海螺 02 无统一单价（分档价在备注里）。
- 换算依赖套餐价：Kling 按 Standard Package 500 美元/3250 Units 换算，Pika 按一次性充值 60 credits = 1 美元换算，Luma 按 Plus 套餐 30 美元/10000 credits 换算，Runway 按 Unlimited 套餐 95 美元/9500 credits 换算；换其他套餐买积分，实际成本会变。
- 按次计费的换算含假设：不足一次按一次算，未经官方确认；月套餐与免费额度未建模；生成失败整条作废的极端情况未计。
- 重生成率与渲染耗时是假设默认值，未经实测校准；漫剧风格 35% 只是建议值。
- 汇率是手动输入的假设值，不是实时汇率。
- 下一步：跑 3-5 个真实剧本验证测算与实际账单的偏差，记进 README；官方定价变了按第 7 节更新。
